# Заранее зафиксированный протокол этапа 8

План записан до запуска SMOKE и REPORT. Исходные и окончательные планы одинаковы:
SMOKE — 5, REPORT — 1000 матриц на каждое n=3–10. Master seed 2018196.
Исследование является приближённым воспроизведением статистики на собственной
выборке, а не точным повтором неизвестных авторских входов.

## Проверка оригинала

Локальный `ipmp2555.pdf`, печатные страницы 12–13 (физические страницы PDF 13–14),
визуально проверены. Таблица 1 полностью совпадает с неизменяемым эталоном
`../reproduction/reference/kurennykh_2018_table1.csv`, SHA-256
`c291a1817a2c9ede3ce9b818f6b26c78cd1da7043f6da07dd8a8bc956fb0bfba`.
Нет ошибок транскрипции. Источник: DOI 10.20948/prepr-2018-196,
https://www.mathnet.ru/rus/ipmp2555 . Локальный PDF не добавляется в Git.

Авторы: C# 7.0/.NET Core 2.0, случайные положительные обратносимметричные МПС
размерности 3–10, статистика по 1000 матриц. Из текста нельзя однозначно
установить N на каждую размерность: не приписываем авторам 1000 на n.
Не опубликованы исходные матрицы, seed/RNG, распределение независимых оценок,
правило назначения размерностей, фильтр первоначального CI, конкретный
способ расчёта весов/рангов, правила равенств, точные правила поддержки j,
отбраковки/повторного выбора рекомендаций, лимит исправлений, аппаратная среда
и прогрев. Шкала 1/9–9 обсуждается; правило отображения выходящих за шкалу
рекомендаций в допустимые значения не определено.

Формула (11) точно задаёт полную сумму квадратов разностей. Процент изменения
описан без формулы и знаменателя. Итерации пояснены как число варьируемых
элементов, без однозначного различения повторных правок и двух обратных ячеек.
Последний столбец — случаи изменения ранга первоначально лучшего объекта;
метод определения приоритетов/равенств не задан.

## Наши заранее выбранные правила

- Равномерный выбор верхних генов из 17 значений существующим DISCRETE_EXPERT.
  Seed — существующий MatrixGenerator.seed(master, DISCRETE_EXPERT, n, sample).
  Никакой фильтрации по CI/K; профиль не участвует в seed. Первые пять входов
  SMOKE и REPORT должны совпадать побитно. ID K2018_nNN_mMMMM.
- Существующий CosineConsistencyCorrector: CI≤0.1, максимум 100 принятых
  исправлений; диапазон [1/9,9], минимальное снижение CI 1e-12, поддержка 0.
  Недопустимые значения отклоняются, не обрезаются и не округляются.
  Все технические решения существующего корректора сохранены: новый порядок
  косинусов после правки, поддержка min(xi_ij,xi_jk), детерминированные равенства,
  только строгое измеренное улучшение CI. Это не полностью заданная C# программа.
- Перроновские правые веса — существующий PerronWeights, с его допуском 1e-12
  и лимитом 10000. Ранги объектов самой МПС: убывание веса, точное равенство
  double разрешается меньшим исходным индексом; позиции последовательные с 1.
  Это не ранжирование альтернатив по внешней таблице из этапа 7.
- E_full = сумма (b_ij−a_ij)^2 по всем i,j — основной показатель, формула (11).
  E_upper = та же сумма по i<j — дополнительный, не подбирается по близости.
- Основной V_upper = 100/m × сумма |b_ij−a_ij|/a_ij по i<j.
  Дополнительные: V_changed — средний процент только окончательно изменённых
  верхних генов (null при нуле таких генов); V_offdiagonal — средний процент
  по всем i≠j. Последние определения наши, не формулы авторов.
- deltaCI = initialCI−finalCI. D — существующее RMS логарифмов отношений
  независимых сравнений. Итерации, длина истории принятых правок, число разных
  затронутых историей пар и окончательно изменённых пар сохраняются отдельно.
- Основная группа ALL включает всё. NEEDS_CORRECTION включает исходный CI>0.1,
  включая неудачи. SUCCESSFUL_REQUIRED — только успешные из NEEDS_CORRECTION.
  Статусы лимита и отсутствия улучшения не исключаются из основных средних.
- Среднее, медиана, выборочная SD (N−1), min/max, число определённых значений.
  95% ДИ среднего — нормальное CLT-приближение mean±1.959963984540054·s/√N.
  При N<2 SD/ДИ null, при N<30 отмечается ненадёжность приближения. Нет
  усечения интервала по 0; это номинальный ДИ, не гарантия покрытия/значимости.
- Время только вызова correct(), включая внутренний пересчёт CI/K самого
  корректора, но без внешнего анализа, генерации, весов, I/O и графиков.
  Прогрев: 10 отдельных входов каждого n, seed с заранее заданной солью
  master XOR 0x5741524d. Прогрев исключён из всех выборок. Измеряемые входы
  обрабатываются блоками n по возрастанию, sample по возрастанию, одним потоком.
  Это прикладное измерение, не JMH; ранние/поздние блоки могут отличаться по JIT.
- Все сравнения с таблицей описательные. Для V отмечается несовпадение
  определений; для времени — разные среда/язык. Авторские проценты изменения
  ранга и разности частот/чисел не вычисляются при неизвестном N на n.
- Исключения/тайм-аут/повреждение данных завершают профиль как FAILED с ID
  и причиной; частичные результаты не выдаются за COMPLETE. Лимит профиля
  7200 с, одного корректора 120 с, архивов суммарно 512 МиБ, Java heap 512 МиБ.

Условия не меняются по наблюдённым результатам. Не выполняется подбор seed,
генератора, варианта V или отдельных удачных входов.
